# Sampling Plan v0.1

## Target corpus

Public-facing SISFIT health-education content for which the original content can be retrieved in full.

The main sampling frame should be created only after a content archive is available with at least:

- stable content ID;
- publication date;
- platform;
- format;
- title/topic;
- full text or stable public URL.

## Exclusions

Exclude:
- user comments and replies;
- direct messages;
- private-group conversations;
- client records;
- individual health data;
- posts where only a title/thumbnail survives;
- exact cross-post duplicates unless platform adaptation is itself the research question.

## Proposed stratification

The first formal corpus should aim to cover heterogeneity rather than maximise sample size.

Suggested strata:

### Format
- long-form article
- short-form social post
- educational carousel/graphic
- course/lesson communication

### Topic
- pain / rehabilitation
- physical activity / fitness
- breathing / sleep / recovery
- women's health
- general health education

### Time
Use broad publication periods that match actual archive coverage rather than inventing artificial yearly quotas.

## Reliability stage

1. Select 10 practice items for coder training; exclude them from study estimates.
2. Independently double-code an initial reliability set of at least 30 eligible items if the archive is large enough.
3. Compute percent agreement + Cohen's kappa per variable.
4. Revise variables that fail the project decision rules in `codebook.md`.
5. If definitions change materially, code a fresh reliability set rather than reporting the training round as final reliability.

## Main analysis

Phase 1 should remain descriptive.

Potential outputs:
- prevalence/distribution of coded communication features;
- differences by format/topic/time;
- feature co-occurrence matrix;
- exploratory latent/profile clustering only if sample size and measurement reliability justify it.

Do **not** initially link features to:
- follower growth;
- engagement;
- health outcomes;
- treatment effects.

Those are separate research questions with additional measurement and governance problems.
