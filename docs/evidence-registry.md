## Release rule

Before adding a new academic claim:
1. identify the source;
2. classify it as VERIFIED_PUBLIC, VERIFIED_INTERNAL, or PENDING_RECONCILIATION;
3. publish only wording supported by that class;
4. keep status labels explicit: Published / Registered / In Progress / Conceptual / Prospective;
5. never infer a DOI, ORCID, author identity or research role from name matching alone.
