# Physical Activity Adherence — Digital Intervention Micro Map v0.1

**身体活动依从性 — 数字干预微地图 v0.1**

A jointly maintained open research project by **Catherine Ge** and **Starr Choi**, hosted within SISFIT Open Research.

## Research question

What mechanisms do digital interventions use to help adults increase or sustain physical activity?

The v0.1 map is structured around a recurring feedback loop:

`measurement → personal feedback → goal / reference → prompt / support → repeat`

A candidate question for v0.2 is:

> Under what conditions does a digital self-monitoring + feedback loop remain behaviorally salient long enough to support physical-activity maintenance?

## Scope

Version 0.1 contains **10 selected adult digital physical-activity intervention studies** coded across:

- population
- target behavior
- adherence problem
- intervention
- behavior-change mechanism/component
- duration
- outcome
- result and DOI

This is a **descriptive convenience micro-map** for structural comparison and correction. It is **not** a systematic review, meta-analysis, or intervention-effectiveness ranking.
